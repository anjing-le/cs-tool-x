# 本机明文 SSH 密码 · 0.0.6

服务器编辑界面使用普通文本字段显示密码，保存到当前用户 Application Support/cs-tool-x/shell.json；用户可直接查看和编辑，不使用系统钥匙串或密文包装。目录 0700、文件 0600 是本机访问权限，不改变文件内容为明文的事实。数据库密码/API Key 的会话内存策略不变。

真实地址、用户、密码和备注只写在仓库外的本机配置中。公开源码只提供通用功能，应用包只包含通用 askpass 启动脚本和原生处理代码，不包含真实服务器配置。仓库公开与本机使用是两个不同边界，不能承诺机器丢失、备份或其他进程读取时绝不会泄露。

有保存密码时，SSH 与 SFTP 共用配置，优先 password 认证且最多一次提示；没有保存密码则继续使用既有 SSH 配置、Agent 或交互认证。askpass 环境只携带配置路径、服务器 ID 和连接端点，不携带密码。原生辅助模式在创建 NSApplication 之前处理并退出，不启动第二个 GUI 客户端。

辅助模式核对配置大小、文件权限/所有者、服务器 ID 与主机/用户/端口，且只回答密码提示；拒绝主机指纹确认、私钥口令、OTP 及其他问题。不通过扫描终端输出注入密码。主机校验保持 StrictHostKeyChecking=ask；未信任或变化的主机先确认指纹，不自动接受。新主机无法自动登录时，可先不保存密码进行交互核对，再配置密码。SFTP 从活动 Shell 服务器打开时沿用同一端点，不在旁边悄悄修改目标。

已加入密码读取、错误端点/ID、权限和提示类型边界测试。真实服务器测试记录留在 ignored .local 中，不在公共文档公布地址和密码；本轮只验证登录、目录读取和微小只读下载，没有上传、远端写入、部署或重启操作。图形化 SFTP 目录/传输队列仍未完成，不能把控制台连接/下载通过描述成已完整替代图形化文件工具。
