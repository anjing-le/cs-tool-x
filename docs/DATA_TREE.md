# 数据连接树

## 连接与原配置

顶层按数据库类型、规范化主机、端口、账号、环境以及 ES URL 基路径分组。账号大小写保持原值，不跨环境合并；ES 的不同账号或基路径保持独立。SQL 数据库名、Redis DB 编号和 TLS 参数不是顶层分组条件。

这是一层显示分组：`connections.json` 仍保存原来的 profile 数组，原 UUID、库名、名称和 TLS 设置不变，无破坏性迁移。界面默认显示对象浏览器，不常驻展示原配置清单；连接设置可编辑所选配置，完整记录可通过 CLI 查询。源记录不会因显示分组自动删除。保存仍通过原文件锁、revision 和原子替换。

同组 TLS 参数不一致时显示提示，子库使用对应原配置的 TLS 设置，不自动降级。相同库有多个来源时，在树中显示一次，全部来源保留在详情；如传输策略不同，可从详情选择具体原配置。

## 层级与交互

| 类型 | 层级 |
| --- | --- |
| MySQL | 连接 → 数据库 → 表/视图 |
| PostgreSQL | 连接 → 数据库 → Schema → 表/视图 |
| Redis | 连接 → 已配置 DB → Keys |
| Elasticsearch | 连接 → 索引 |

初始只显示连接入口；展开 SQL/Redis 连接先显示已配置的库/DB，不发网络请求。选择根节点显示原配置详情；“读取可见库”按当前账号权限读取 MySQL/PG 库清单，不扫描表或业务数据。服务器发现的库不自动写入配置，也不证明业务环境与连接标签一致。

展开库/Schema 触发相应目录请求；未连接时先显示连接表单。PG 各 database 使用独立会话，不用跨库 SQL 伪装成 Schema。目录展开后缓存，双击相应节点或在工作区点击“读取目录”可重读；不轮询。点击表最多预览 100 行；ES 索引与 Redis Key 使用现有有界预览。Redis DB 列表合并当前已保存 DB 与 INFO keyspace 中有数据的 DB，仍不代表全部空 DB；Keys 逐批 SCAN，可点击下一批。

原有查询编辑器、历史、结果与断开行为保留。左右方向键展开/收起，Enter 激活所选节点。节点显示与主机/原名称完整 tooltip 使用项目 PaperControls、Theme 和自定义指针。

## 资源与凭据

- 同时最多 4 个数据会话，每个 SQL 池最多 2 个连接；第五个会话提示先断开。切换节点不自动关闭忙会话。
- 密码/API Key 在本次应用内存中复用，按连接身份和 TLS/协议策略隔离。断开某连接的最后一个会话时清理该连接的缓存凭据与目录缓存；退出释放内存凭据。可选择本机 data-credentials.json 明文保存（0600，不留备份）；不用钥匙串。
- 每次目录结果最多 500 项，截断时明确提示；树缓存总量最多 5000 项，Redis 单个 DB 可见 Key 缓存最多 500 个。单个对象名超过 4 KiB 时不加入树并显示提示，显示文本最多 200 字符；树节点 ID 使用名称摘要，避免巨长 Key 膨胀路径。到达预算后需要断开不用的连接，不继续无限积累。
- SQL 元数据仅执行只读查询；tables 范围使用绑定参数。数据库清单、Schema 与表分开请求，不一次预取所有数据库的所有表。响应过期、节点已替换或会话已断开时不写回旧节点。
- SQL 不支持通用元数据翻页；超出 500 的目录会截断。没有把目录上限等同于服务端成本、网络接收或进程内存的完整上限；客户端超时仍不等于服务端取消。

## 验证

Core 测试覆盖账号/环境/端口/类型分组边界、PG database 与 Redis DB 子层、全部源 UUID 保留、TLS 策略隔离。AppKit 离屏组件检查覆盖四层展开、行构建、刷新后展开状态、断开后旧节点失效；该检查不是对安装客户端的鼠标键盘验收。

本地隔离 MySQL/PG 联调覆盖数据库、Schema、表清单以及带 SQL 语法的恶意 scope 不扩大查询范围；现有引擎测试继续验证只读与结果上限。真实目标的验证结果只保存在本机 ignored 记录中，公开源码不包含公司地址、账号、密码或业务库清单。

## 0.0.9 极简工作区

固定连接选择器切换目标，目录树只展开当前目标，避免大量库把其他连接挤到长列表末尾。右侧“浏览”显示对象表、已加载对象筛选和刷新；“查询”显示 SQL/DSL/Key 模式编辑器与结果。表预览可生成带正确标识符引号的 SELECT 草稿，已经修改过的查询不会被覆盖。结果筛选保留原始行索引，双击详情不会指向筛选前的错误行。

切换模式保留本次查询、结果和历史；目录请求完成后只更新仍在显示的浏览页，不把正在编辑的查询页切回目录。连接新发现的数据库默认只在当前会话保留，不自动增加持久化配置；用户仍可显式保存。连接设置要求先断开对应会话，以免重复连接覆盖工作区。

交互研究参考 [Elasticvue v1.8.0](https://github.com/cars10/elasticvue/tree/v1.8.0) 的对象筛选表、查询编辑器与结果区；此版本独立以 Swift/AppKit 实现，没有复制或打包其 Vue/TypeScript 源码，也不引入它的节点/分片/快照管理模块。

## 0.0.10 直接打开

- 左侧单击只选中；双击、回车打开并自动连接，复用已存在的相同会话。展开箭头按需加载目录，不替换右侧编辑器。连接选择器切换后直接加载该连接。
- 右侧显示目录、对象数据或查询；不再要求再填连接表单、再点一次连接。新建、编辑、断开放在左侧连接菜单。Shell 服务器同样单击选择，双击或回车打开 SSH 会话。
- 已保存的凭据由本机 `data-credentials.json` 提供，权限 0600、当前用户所有、不保留秘密备份，不进入 Git、app 或 OTA，不使用钥匙串。按账号、地址、环境和传输策略隔离，同账号不同库复用；明确保存空凭据支持匿名 ES。仅缺少凭据时显示补充登录小表单；连接失败就地显示，不自动重试。
- 自动连接预留会话名额，活动与连接中合计最多 4 个。同一 profile 的连续激活只发一个 connect，保留最新打开目标；切换模块、连接或查询编辑后，较早完成的连接不会抢占当前页面。展开元数据仍受 500 项/5000 节点预算约束。
- 参考 [DataGrip 的双击表打开数据](https://www.jetbrains.com/help/datagrip/tables-view-data.html)；交互原则采用本项目实现，未复制其界面或代码。
