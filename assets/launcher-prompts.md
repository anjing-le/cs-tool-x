# Homepage entrance artwork

Generated with the built-in imagegen tool. Style references: CreatorX writing-v2.png (character) and video-v1.png (wax-crayon and full-bleed colored paper). Sibling files were read only.

Three full-bleed vertical panels, no card plate, frames, borders or gutters. Labels are app-rendered only during hover/focus. Artwork is a visual metaphor for existing modules, not a screenshot or a claim of new capabilities.

## shell

Use case: illustration-story. Production artwork for a macOS developer-tool game-like entrance screen. Style references: image 1 defines the recurring character identity; image 2 defines the dense wax-crayon drawing and colored paper treatment. Draw the SAME cute young male with egg-yolk-yellow messy hair, black hoodie, dot eyes, tiny calm smile, blush and childlike proportions. Rough thick dark-brown/black crayon outlines, visible wax grain, warm handcrafted storybook feeling, muted sage/cream/powder-blue palette. Do not use a polished vector, anime, realistic face, glossy 3D, software screenshot, tiny lettering or generic SaaS icon. Tall PORTRAIT 2:3 image. IMPORTANT: this will fill a narrow full-height third of a desktop window, so all key objects and the character must fit in the central 55% of image width and central 65% of height, with surrounding atmosphere extending to every canvas edge; no frame, white margin, rounded card, border, vignette or transparent background. Quiet uncluttered but immersive scene, like a gentle game chapter selection doorway. NO text, NO title, NO letters, NO logos, NO watermark. One character, one clearly readable primary activity. Do not copy the exact activities in the reference images.
Scene: a cozy small remote-server workshop. The character at a small wooden desk operating a simple terminal monitor showing only a white angular prompt symbol and a few short abstract strokes, no actual text. Beside the monitor are a compact sage server tower and two pale file folders connected by one simple curved transfer cable, expressing terminal plus file transfer together. A faint wooden floor and warm soft golden paper wall fill the ENTIRE canvas; lightly sketched workshop window far behind. Make the central terminal and server silhouette instantly legible. Background color warm muted cream-gold, never pure white.
