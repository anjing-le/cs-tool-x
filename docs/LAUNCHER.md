# 插画首页

0.0.21 起采用“上三、下一”的四区结构：上方三个等宽入口为 Shell（含终端与文件传输）、数据、Git，下方整行为空的第四功能预留区，没有文字、图标或点击行为，不将其当作已实现功能。区域之间没有白卡片、边距、间隙、圆角底板或框线；首页没有常驻标题与说明，入口名在悬停或键盘焦点时出现，保留辅助功能标签。三个真实入口按原路由进入模块，返回首页仍用 Cmd+1。

视觉参照 `anjing-happy-creator-Journey` 会话及 CreatorX 当前首页素材，使用同系列黄发黑卫衣人物、粗蜡笔笔触和低饱和配色。为适应本次无白边、游戏选关式入口要求，新图为全幅彩纸场景，未照搬参考项目的透明底留白布局，也未修改兄弟项目。

三个正式 PNG 位于 `Resources/Entrances/{shell,data,git}.png`，由内置 imagegen 生成，完整提示词与参考用途位于 [launcher-prompts.md](../assets/launcher-prompts.md)。不将参考文件作为运行依赖，图像仅为已实现模块的视觉入口，不代表额外连接或操作已完成。

按 CreatorX 的 contain 思路等比例完整放入分区。上排高度不超过任一原图按列宽完整缩放后的高度，且最多占窗口 80%；这样不在上方生成横向色带，下方至少留出 20% 作为统一预留区域。宽屏下图片旁的余量使用场景色承托。最小 980×680、标准 1440×850 及宽屏 1920×900 做离屏检查。悬停只改变明暗/标签，不放大、挤动或裁掉图片。运行时仅解码固定三张本地资源，解码与文件读取在后台执行，单文件不超过 8 MiB、长边最多 1536 像素，返回首页复用缓存；这些是资源预算，不是进程总内存承诺。只在状态变化时更新画面，不做持续重绘，遵守减少动态效果设置。正式打包必须带齐三张图。

源码构建、组件渲染、安装包资源与安装后实际鼠标/键盘交互分别验收；离屏渲染不等于安装窗口自动化。
