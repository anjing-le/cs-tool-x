# 客户端 UI 约定

自有界面沿用 ShellX 暖纸张、鼠尾草绿、浅色边线和圆角。Theme 是 AppKit 与 Shell SwiftUI 主色的共同来源；PaperControls 提供按钮、勾选、安全/普通字段、下拉、提示与详情框，避免重新引入系统粉色焦点、渐变 bezel 和原生菜单列表。

连接表单无标题栏、固定 34pt 字段与 8pt 行距、540×650 紧凑框体；焦点为绿色描边，选区为浅绿，禁用态降低对比度。密码/API Key 仍使用 NSSecureTextField 安全编辑语义，不保存到钥匙串。中文编辑、密码遮罩、错误信息和辅助功能标签保留。

下拉列表是带阴影的无边框子窗口，列表最多 320pt，长列表滚动；支持 Tab 焦点进入、方向键打开/选择、Return 确认、Escape 关闭，点击外部或应用失去激活也关闭。关闭连接表单清理子菜单和监听。无持续鼠标轮询；弹窗与列表沿用统一自定义光标。

数据历史、单元格详情、错误与开发构建更新提示均复用主题控件。结果表头、选中行和查询选区也使用主题色。系统菜单栏、文件面板和 Sparkle 自带的正式更新流程仍使用其提供的界面，未声称已自绘这部分。

## 0.0.3 验证

原生客户端实际检查：首页/数据跳转、紧凑表单外观、中文与普通文本输入、密码遮罩、勾选、MySQL → PostgreSQL 的端口/用户名切换、Elasticsearch 的字段禁用与 API Key、环境鼠标选择、Tab → 方向键 → Return 的下拉选择、Escape 关闭下拉、空主机本地校验、取消与统一提示框。未对真实业务地址发起连接；表格/历史/单元格详情的样式已接入共用组件，本轮未新增真实查询验收。
