# README 配图

使用内置 image_gen 生成，参考 macos-x 的纸张、铅笔和蜡笔产品介绍方式，以及 cs-tool-x 现有工具箱图标。各图旁的 `.prompt.txt` 保存完整提示词，封面返修另存 `.edit.prompt.txt`。

- `00-brand.png`：工具箱品牌主视觉，README 首图与官网挂牌共用。
- `01-cover.png`：横版总览，Shell、数据、Git、CLI / Agent 四项概览。CLI 文字已返修为实际存在的 doctor / schema。
- `02-shell.png`：分组、终端分屏、附属 SFTP 控制台。未展示图形化文件管理。
- `03-data.png`：连接目录、查询与示例表。SQL 只读。
- `04-git.png`：本地提交历史与文件详情，只读。
- `05-cli.png`：doctor / schema 与 JSON 输出示意，无需窗口或常驻服务。

这些是说明插画，不是真实运行截图、环境连接结果或性能证据。场景示例不包含真实地址、账号、凭据或个人数据。README 保持完整画幅，封面链接最新版下载，其余图片链接原图；原技术说明保存在 `docs/DEVELOPMENT.md`。

官网 anjing-products 使用相同六张 PNG 派生的 WebP，转换质量 92，不裁切、拉伸或重绘内容。品牌图及功能图保持完整画幅，主视觉上下边缘由网页柔化以衔接纸底。官网页面负责挂绳、圆角、卡片厚度、翻转与投影。插画中的细线是示意界面的轮廓，不是第二层外卡牌。
